# Data acceptance checklist

Confirm dataset owner/permission; data freshness and timezone; entity grain; natural keys; nulls; deduplication; outliers; join multiplicity; KPI units; denominator and cohort construction; retention censoring; PII/regulated financial data masking; sample size; confidence and counterfactual explanations; reproducible code; clear `NOT_RUN` for missing checks.

If a chart is needed, distinguish visualization specification from computed data. Do not assert data is anonymized merely because obvious names were removed.
